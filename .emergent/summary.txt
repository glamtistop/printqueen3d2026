<analysis>**original_problem_statement:**
The user wants to build a beautiful, modern e-commerce website for their 3D printing business, named Print Queen 3D.

PRODUCT REQUIREMENTS:
- **Core Functionality**:
  - User login/authentication capabilities (Google Social Login preferred).
  - An admin page for adding and managing products.
  - Stripe integration for payments.
- **Design & UX**:
  - Modern look with a gradient background and parallax effects.
  - The design should be elegant, using blue, green, and yellow as primary colors.
  - The final design should exactly mimic the user's existing website: , including banner images, logo, favicon, fonts, and footer content.
  - A fixed navigation bar at the top of the page on both desktop and mobile.
- **Homepage Layout**:
  - Replicate the layout from the reference site:
    - A hero banner section.
    - A grid of 6 category squares below the banner (6 per row on desktop, 2 per row on mobile).
    - A Featured Products section below the categories.
- **Custom Product Page (NFC Stand)**:
  - A detailed product page for a customizable NFC Stand.
  - A main product image should be displayed at the top.
  - Users must select from a series of options before they can purchase:
    1.  **Base Option**: A grid of choices (e.g., 2 NFC, 3 NFC with card holder) with associated images. The layout should be 3 options per row.
    2.  **Color Selection**: Primary and secondary color choices from a dropdown menu with 32 color swatches. The dropdown should have a good user experience, not feel cramped, and work well on mobile. The user settled on an expanding card animation for this.
    3.  **Logo Upload**: A field for the user to upload their logo.
    4.  **NFC Links**: Input fields for multiple links.
  - The price should update dynamically based on selections.
  - The Add to cart or Purchase button should be disabled until all options are selected.
  - Upon purchase completion, an email with the custom order details should be sent to the business owner.

**User's preferred language**: English
